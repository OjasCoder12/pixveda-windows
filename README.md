## 🚀 How to Install and Run on Windows

PixVeda for Windows is portable and requires no complex installer setup:

### Step 1: Download the Package
Click the [**Download for Windows**](https://github.com/OjasCoder12/pixveda-windows/releases/latest/download/PixVeda-Windows-x64.zip) button above to download `PixVeda-Windows-x64.zip`.

---

### Step 2: Extract the Archive
1. Open your **Downloads** folder.
2. Right-click `PixVeda-Windows-x64.zip` and select **Extract All...**.
3. Choose a destination folder (e.g., `C:\Program Files\PixVeda` or your user folder) and click **Extract**.

---

### Step 3: Launch PixVeda
1. Open the extracted `PixVeda` folder.
2. Double-click **`pixveda_app.exe`** to start PixVeda.

---

### Step 4: Windows Defender SmartScreen (If prompted)
Because this is an independent application release, Windows SmartScreen may show an alert on first launch:

1. Click **More info**.
2. Click **Run anyway**.

---

### 💡 Pro Tip: Create a Desktop Shortcut
- Right-click `pixveda_app.exe` ➔ Select **Show more options** (on Win 11) ➔ **Send to** ➔ **Desktop (create shortcut)**.
- Or right-click `pixveda_app.exe` ➔ **Pin to Start** / **Pin to taskbar**.

## 🛠️ Troubleshooting & FAQs

### ❓ "VCRUNTIME140.dll" or missing runtime error
- Make sure you have the standard Microsoft Visual C++ Redistributable installed. It can be downloaded directly from Microsoft: [Visual C++ Redistributable 2015–2022 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe).

### ❓ How do I update to future versions?
- Download the new `PixVeda-Windows-x64.zip` from the [Releases](https://github.com/OjasCoder12/pixveda-windows/releases) page and extract it to overwrite the old files. Your account login and cloud data are saved securely.

## ✨ About PixVeda

PixVeda is an all-in-one AI study companion designed specifically for school and college students:
- 🤖 **AI Chat Tutor:** Step-by-step concept explanations tailored to student grade and syllabus.
- 🗂️ **Interactive Flashcards:** Spaced-repetition study decks to master topics quickly.
- 🧠 **Mind Maps:** Visual diagrams and concept hierarchies generated on the fly.
- ⏱️ **Focus Sessions:** Dedicated study timer with integrated assistance.
- 📝 **Smart Notes & Summarizer:** Convert long documents and textbook chapters into key takeaways.
- 🎯 **Practice Quizzes:** Instant MCQs and test questions with real-time feedback.
- 📅 **Day Planner:** Timetable and guided weekly study plans.
